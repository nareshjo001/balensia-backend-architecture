Data boundary

MongoDB (with GridFS) is the source of truth. Redis caches reads and coordinates jobs. The ML service, LLM/STT providers, Brevo and FCM do specialist work.

MongoDBRedisMLLLMBrevoFCM
Structured data or a controlled error code returns through the API
i

Core idea: MongoDB is the source of truth; Redis is disposable. A committed financial write always succeeds. Its budget and report follow-ups are reserved before the write, fenced by revision, and repaired on read if anything failed. The web role serves traffic; the worker role owns the scheduled jobs.

    HTTP request lifecycle

    A client call passes through Express and returns one controlled response. The platform routes traffic using /health/ready.

    • Request ID → metrics → Helmet → CORS → JSON parser
    • Group or feature limiter → JWT + live session → Joi / upload checks
    • Controller reserves sync work, commits the write, then synchronizes
    • Unhandled errors are logged and reported with request ID context

    Scheduled jobs under Redis leases

    Nine cron modules load only on the worker (or a single "all" process). Times are server-local.

    06 / Honest boundaries

    What this backend guarantees—and what still needs attention

    These distinctions keep the service explanation accurate and make its next engineering priorities visible.

    Guaranteed Capabilities

    Architectural guarantees strictly enforced across persistence, session lifecycles, and reliability engines.

    It does

    Enforce user ownership

    Every protected query includes req.userId. Another user's receipt, export, import session or recurring template returns the same 404 as a missing one.

    It does

    Keep committed writes consistent

    PendingSync reservations, revision-fenced recomputes and read-time repair mean a crash between the write and its budget/report update is recovered, not lost.

    It does

    Expire and rotate sessions

    Access tokens expire (15m default), refresh sessions rotate on every use, and reuse of an old refresh token revokes every session.

    It does

    Survive a Redis outage

    Startup waits five seconds and then serves; caches fall through to MongoDB and each job is either fail-open or fail-closed.

    It does

    Build deterministic analytics

    Report scores, signals and forecasts come from analyzers and a robust statistical trend, not from an ML or LLM guess.

    Architectural Non-Goals

    Intentional architectural scope boundaries—what the Node.js backend deliberately delegates or forbids.

    It does not

    Train ML models itself

    The backend records feedback and calls /retrain-model; the separate ML service owns training, validation and activation.

    It does not

    Let AI write financial data

    SIA answers are read-only and parse-expense returns a suggestion; the user saves it through the normal Add Expense path.

    Active Limits & Maintenance

    Confirmed technical boundaries, distributed clock nuances, and maintenance notes in current backend code.

    Current limit

    Group limiter is IP-keyed and per-process

    apiLimiter runs before verifyToken sets req.userId, and no limiter configures a shared store, so counts live in each instance's memory.

    Current limit

    SIA chat answers are not number-checked

    The /ask validator checks format, IDs and internal field names only. Only the monthly summary cross-checks every amount against cited facts.

    Current limit

    Queued exports live on one instance's disk

    Exports of 5,000+ rows are written by the worker to backend/generated-exports, while downloads are served by the web service, a separate service in render.yaml.

    Current limit

    Account purge misses five collections

    Tier B does not delete ExportRequest, ImportSession, NotificationPreference, AiSummaryPreference or SiaPreference records.

    Current limit

    Money is still float-first

    Legacy float amounts remain authoritative; render.yaml keeps MONEY_MINOR_DUAL_WRITE_ENABLED "false" while the DAT-001 migration finishes.

    Current limit

    Several clocks are in play

    Budget months use server-local time, recurring due dates the UTC 1st, skips and projections APP_TIME_ZONE, and crons run on server-local time.

    Current limit

    Receipts are images only

    Only JPEG and PNG are accepted (PDF returns 415). Parsing uses heuristics: the merchant is the first two words, and there are no line items or category.

    Current limit

    Error aggregation is a no-op by default

    Errors are reported through a redacting no-op transport. The Sentry transport requires @sentry/node, which is not a dependency.

    Recently Resolved Improvements

    Previously identified limitations that have been engineered, resolved, and verified in the current backend codebase.

    Resolved in 9a43723

    On-demand financial export deletion

    DELETE /api/export/:id safely removes MongoDB ExportRequest documents and purges physical files from backend/generated-exports on demand, preventing stale artifacts.

    Resolved in 9a43723

    Synchronous exports recorded in database

    Small exports (< 5,000 rows) now persist an ExportRequest record with status 'ready', ensuring synchronous downloads are traceable in the user's past export history.

    Resolved in 9a43723

    Multi-format date parsing resiliency

    Centralized dateParsing.js utility provides robust parsing for ISO strings, custom formats (dd-MM-yyyy, yyyy-MM-dd), and timezone offsets, guarded by test suites.

    The architecture in one sentence

    Routes protect the contract. Controllers commit the write. Sync recovery keeps derived data honest. MongoDB remembers. Redis accelerates. Workers keep the system moving.
